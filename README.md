# 📸 Screenshot to Code

> Upload any screenshot → Get clean HTML + Tailwind CSS code instantly.

This is a lightweight clone of the viral repo `abi/screenshot-to-code` (76k+ stars) - built with pure HTML, CSS & JS. No API key needed.

### 🚀 Live Demo
**https://farimazhar.github.io/screenshot-to-code/**

### ✨ Features
- 📤 Upload any UI screenshot (PNG, JPG)
- ⚡ Instant HTML + Tailwind code generation
- 👁️ Live preview
- 📋 One-click copy
- 📱 Works as PWA - Install on phone
- 100% Free & Offline

### 🛠️ How It Works
1. Upload your screenshot
2. Click "Generate Code"
3. Copy the code & use anywhere

### 💻 Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- PWA Support
